# ☕ Java Swing GUI Guide

Welcome, future developers! 💻✨

This guide will help you create a **Java Swing application** with two windows: a Login page and a Welcome page.

## 🚀 What You’ll Learn

- Explore GUI components and buttons.
- Design windows using NetBeans.
- Add messages and button actions.
- Move between two windows.
- Test your application and have fun! 🎉

## 🛠️ What You Need

- Java JDK
- NetBeans IDE
- A web browser

## 💡 Ready to Start?

Open the guide, follow the steps, and build your own GUI!
